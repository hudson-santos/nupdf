# Imagens da listagem na Microsoft Store

Geradas por `gerar_imagens.py` a partir do próprio NuPDF, com documentos e
certificado **fictícios** (nenhum dado real). Para gerar de novo depois de mudar o
app, na raiz do projeto:

```
venv\Scripts\python.exe ms\gerar_imagens.py
```

## Onde usar no Partner Center (Detalhes da listagem na Store)

| Arquivo | Campo | Tamanho |
|---|---|---|
| `captura-01-inicio.png` | Capturas de tela (Área de Trabalho) | 1920 x 1080 |
| `captura-02-leitura-e-miniaturas.png` | Capturas de tela | 1920 x 1080 |
| `captura-03-destaques-por-prioridade.png` | Capturas de tela | 1920 x 1080 |
| `captura-04-assinatura-validada.png` | Capturas de tela | 1920 x 1080 |
| `captura-05-assinar-com-certificado.png` | Capturas de tela | 1920 x 1080 |
| `captura-06-tema-escuro.png` | Capturas de tela | 1920 x 1080 |
| `logo-1x1-2160.png` | Logotipos da Store - Arte de caixa 1:1 (obrigatório) | 2160 x 2160 |
| `poster-2x3-1440x2160.png` | Logotipos da Store - Arte de cartaz 2:3 (recomendado) | 1440 x 2160 |
| `hero-16x9-3840x2160.png` | Imagem hero 16:9 (opcional) | 3840 x 2160 |

Legendas sugeridas para as capturas:

1. Tela inicial com os arquivos recentes
2. Leitura com miniaturas das páginas
3. Destaques por prioridade: baixa, média, alta e resolvido
4. Assinatura digital ICP-Brasil validada
5. Assinatura com o certificado digital instalado no Windows
6. Tema escuro
